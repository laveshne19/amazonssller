# Amazon listings

Listing copy for our Amazon Seller Central products: titles, bullets, descriptions, backend keywords and the notes behind them.

Nothing in this repo changes a live listing by itself. Copy gets reviewed here first, then pushed to Seller Central by hand or through the Selling Partner API after sign off.

## Products

| Product | Folder | Status |
|---|---|---|
| Recolx Tap AI Voice Recorder | [listings/recolx-tap](listings/recolx-tap) | Draft, needs fact check |

## How each folder is laid out

- `listing.md` is the copy ready to paste into Seller Central.
- `seo-geo-notes.md` explains the keyword choices, the Rufus and AI search angle, and any facts that still need checking.
